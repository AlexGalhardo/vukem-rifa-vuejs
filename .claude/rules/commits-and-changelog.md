# Commits and changelog

- Conventional Commits (commitlint, scopes in `commitlint.config.js`), English, imperative.
- Keep a Changelog 1.1.0: add entries under `## [Unreleased]` in the same commit as the change.
- SemVer: `v0.N.0` per finished PLAN.md phase; tag pushes trigger `.github/workflows/release.yml`.
